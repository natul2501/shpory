Canvas API
 Canvas API передбачає роботу із елементом <canvas>. Цей елемент є як би область малювання, до якої можна отримати доступ у коді JavaScript і на якій можна намалювати різні фігури, помістити на неї зображення, навіть маніпулювати відео та інше.
Розділи: створення 2d-фігур | задати властивості фігур | трансформації | довільні фігури та лінії | текст
2. Створення 2d-фігур
strokeRect(x, y, w, h) - малює контур прямокутника(x, y - координати лівого верхнього кута; w - ширина, h - висота)
Подивитися текст коду const canvas = document.getElementById("canvas"); const context = canvas.getContext("2d"); context.strokeRect (10, 10, 100, 100);
fillRect(x, y, w, h) - прямокутник із заливкою(x, y - координати лівого верхнього кута; w - ширина, h - висота)
Подивитися текст коду const canvas = document.getElementById("canvas"); const context = canvas.getContext("2d"); context.fillRect (10, 10, 100, 100);
clearRect(x, y, w, h) - очистити від заливки область прямокутника(x, y - координати лівого верхнього кута; w - ширина, h - висота)
Подивитися текст коду const canvas = document.getElementById("canvas"); const context = canvas.getContext("2d"); context.fillRect (10, 10, 100, 100); context.clearRect (15, 15, 90, 90);
3. Задати властивості фігур
strokeStyle - задати колір ліній чи контуру (у форматі rgb, rgba, #ХХХХХХ або словом)
Подивитися текст коду const canvas = document.getElementById("canvas"); const context = canvas.getContext("2d"); context.strokeStyle = "#ff0000"; context.strokeRect (10, 10, 100, 100);
lineWidth - задати товщину лінії (в пікселях)
Подивитися текст коду const canvas = document.getElementById("canvas"); const context = canvas.getContext("2d"); context.fillStyle = "#c7ecee"; context.fillRect (10, 10, 100, 100); context.strokeStyle = "#22a6b3"; context.lineWidth = 15.5; context.strokeRect (10, 10, 100, 100);
setLineDash() - як параметр приймає масив чисел, які встановлюють відстані між лініями
Подивитися текст коду const canvas = document.getElementById("canvas"); const context = canvas.getContext("2d"); context.strokeStyle = "red"; context.setLineDash([15,5]); context.strokeRect(10, 10, 100, 100); context.strokeStyle = "blue"; context.setLineDash([2,5,6]); context.strokeRect(130, 10, 100, 100); context.strokeStyle = "green"; context.setLineDash([2]); context.strokeRect(250, 10, 100, 100);
lineJoin - тип з'єднання ліній фігури: пряме, заокруглене або конічне
Подивитися текст коду const canvas = document.getElementById("canvas"); const context = canvas.getContext("2d"); context.lineWidth = 20; context.lineJoin = "miter"; context.strokeRect(10, 20, 100, 100); context.lineJoin = "bevel"; context.strokeRect(140, 20, 100, 100); context.lineJoin = "round"; context.strokeRect(270, 20, 100, 100);
fillStyle - задати колір заливки фігури (у форматі rgb, rgba, #ХХХХХХ або словом)
Подивитися текст коду const canvas = document.getElementById("canvas"); const context = canvas.getContext("2d"); context.fillStyle = "#ee5253"; context.fillRect (10, 10, 100, 100);
globalAlpha - прозорість заливки
Подивитися текст коду const canvas = document.getElementById("canvas"); const context = canvas.getContext("2d"); context.fillStyle = "blue"; context.fillRect(50, 50, 100, 100); context.globalAlpha = 0.5; context.fillStyle = "red"; context.fillRect(100, 100, 100, 100);
createPattern() - заливка зображенням фігури (repeat - повторення зображення, repeat-x - повторення по осі х, repeat-y - повторення по осі у, no-repeat - без повторення)
Подивитися текст коду const canvas = document.getElementById("canvas"); const context = canvas.getContext("2d"); const img = new Image(); img.src = "./img/ap2.png";
img.onload = function() { const pattern = context.createPattern(img, "repeat"); context.fillStyle = pattern; context.fillRect(10, 10, 480, 280); context.strokeRect(10, 10, 480, 280); };
createLinearGradient(x0, y0, x1, y1) - створення лінійного градієнту (x0, y0 - початкові координати градієнта щодо верхнього лівого кута, x1, y1 - відповідно кінцеві координати)
x0 = x1 - горизонтальний градієнт, y0 = y1 - вертикальний градієнт
Подивитися текст коду const canvas = document.getElementById("canvas"); const context = canvas.getContext("2d");
const gradient = context.createLinearGradient(10, 30, 150, 150); gradient.addColorStop(0, "blue"); gradient.addColorStop(1, "yellow"); context.fillStyle = gradient; context.fillRect(10, 30, 150, 150); context.strokeRect(10, 30, 150, 150);
const gradient2 = context.createLinearGradient(250, 30, 150, 150); gradient2.addColorStop(0, "blue"); gradient2.addColorStop(0.3, "red"); gradient2.addColorStop(1, "yellow"); context.fillStyle = gradient2; context.fillRect(170, 30, 150, 150); context.strokeRect(170, 30, 150, 150);
addColorStop(offset, color) - задання опорних точок градієнту (offset - зміщення опорної точки градієнту, color - її колір)
createRadialGradient(x0,y0,r0,x1,y1,r1) - створення радіального градієнту (x0, y0 - координати центру першого кола, x1, y1 - координати центру другого кола, r0, r1 - радіуси відповідно першого і другого кіл)
Подивитися текст коду const canvas = document.getElementById("canvas"); const context = canvas.getContext("2d"); const gradient = context.createRadialGradient(120,100,100,120,100,30); gradient.addColorStop(0, "blue"); gradient.addColorStop(1, "white"); context.fillStyle = gradient; context.fillRect(50, 30, 150, 150); context.strokeRect(50, 30, 150, 150);
shadowColor - колір тіні
Подивитися текст коду const canvas = document.getElementById("canvas"); const context = canvas.getContext("2d"); context.fillStyle = "#3498db"; context.shadowOffsetX = 10; context.shadowOffsetY = 10; context.shadowBlur = 10; context.shadowColor = "#9999"; context.fillRect(10, 10, 200, 200);
shadowBlur - число пікселів для встановлення розмиття тіні
shadowOffsetX - горизонтальне зміщення в пікселях зліва або справа при від'ємному значенні
shadowOffsetY - вертикальне зміщення в пікселях зверху або знизу при від'ємному значенні
4. Трансформації
translate(x, y) - переміщення по осі x та y відносно поточного розташування (в пікселях)
Подивитися текст коду const canvas = document.getElementById("canvas"); const context = canvas.getContext("2d"); context.fillStyle = "blue"; context.fillRect(100, 50, 100, 100); context.globalAlpha = 0.5; context.fillStyle = "red"; context.translate(50, 25); context.fillRect(100, 50, 100, 100);
rotate(angle) - поворот на заданий кут angle (в радіанах) відносно точки з координатами (0,0)
Подивитися текст коду const canvas = document.getElementById("canvas"); const context = canvas.getContext("2d"); context.fillStyle = "blue"; context.fillRect(100, 50, 100, 100); context.globalAlpha = 0.5; context.fillStyle = "red"; context.rotate(.52); //поворот на 0.52 радіан або 30° context.fillRect(100, 50, 100, 100);
scale(xScale, yScale) - розтягування по осі х у xScale раз і по осі у у уScale разів
Подивитися текст коду const canvas = document.getElementById("canvas"); const context = canvas.getContext("2d"); context.fillStyle = "blue"; context.fillRect(100, 50, 100, 100); context.globalAlpha = 0.5; context.fillStyle = "red"; context.scale(1.5, 1.5); context.fillRect(100, 50, 100, 100);
transform(a,b,c,d,e,f) - матриця трансформацій:
a - масштабування по осі Х
b - поворот навколо осі Х
c - поворот навколо осі У
d - масштабування по осі У
e - горизонтальне зміщення
f - вертикальне зміщення
Подивитися текст коду const canvas = document.getElementById("canvas"); const context = canvas.getContext("2d"); context.fillStyle = "blue"; context.fillRect(100, 50, 100, 100); context.globalAlpha = 0.5; context.fillStyle = "red"; context.transform( Math.cos(Math.PI/6), Math.sin(Math.PI/6), -1 * Math.sin(Math.PI/6), Math.cos(Math.PI/6), 0, 0); context.fillRect(100, 50, 100, 100);
setTransform(a,b,c,d,e,f) - заміна трансформацій (параметри аналогічно transform)
resetTransform() - скидання трансформацій для наступних фігур
Подивитися текст коду const canvas = document.getElementById("canvas"); const context = canvas.getContext("2d"); context.fillStyle = "blue"; context.fillRect(100, 50, 100, 100); context.globalAlpha = 0.5; context.fillStyle = "red"; context.translate(50, 25); context.fillRect(100, 50, 100, 100); context.fillStyle = "green"; context.resetTransform(); context.fillRect(0, 10, 100, 100);
Довільні фігури та лінії
1| beginPath() - ініціація початку шляху
Подивитися текст коду const canvas = document.getElementById("canvas"); const context = canvas.getContext("2d"); context.beginPath(); context.moveTo(20, 100); context.lineTo(140, 10); context.lineTo(260, 100); context.stroke();
2| moveTo(x, y) - задання початкової точки з координатами х та у
3| lineTo(x, y) - провести лінію від заданої точки до точки з координатами х та у
4| stroke() - відобразити результат на екрані
closePath() - замикання шляху
Подивитися текст коду const canvas = document.getElementById("canvas"); const context = canvas.getContext("2d"); context.beginPath(); context.moveTo(20, 100); context.lineTo(140, 10); context.lineTo(260, 100); context.closePath(); context.stroke();
Path2D - об'єкт, що використовується для розмежування шляхів
Подивитися текст коду const canvas = document.getElementById("canvas"); const context = canvas.getContext("2d"); context.beginPath();
const path1 = new Path2D(); path1.moveTo(20, 100); path1.lineTo(140, 10); path1.lineTo(260, 100); path1.closePath(); context.strokeStyle = "blue"; context.stroke(path1);
const path2 = new Path2D(); path2.moveTo(20, 110); path2.lineTo(140, 200); path2.lineTo(260, 110); path2.closePath(); context.strokeStyle = "red"; context.stroke(path2);
fill() - заливка замкнутого шляху
Подивитися текст коду const canvas = document.getElementById("canvas"); const context = canvas.getContext("2d"); context.beginPath(); context.moveTo(20, 100); context.lineTo(140, 10); context.lineTo(260, 100); context.closePath(); context.fill(); context.stroke();
clip() - обрізання всього, що виходить за межі попереднього об'єкту
Подивитися текст коду const canvas = document.getElementById("canvas"); const context = canvas.getContext("2d");
context.beginPath(); context.rect (10, 10, 100, 100); context.clip();
context.moveTo(20, 100); context.lineTo(140, 10); context.lineTo(260, 100); context.closePath(); context.stroke();
rect(x, y, w, h) - малює прямокутник(x, y - координати лівого верхнього кута; w - ширина, h - висота)
Подивитися текст коду const canvas = document.getElementById("canvas"); const context = canvas.getContext("2d"); context.beginPath(); context.rect (10, 10, 100, 100); context.stroke();
arc(x, y, r, start,end, clockwise) - малює коло або сегмент кола
(x, y - координати центру,
r - радіус,
start - початковий кут,
end - кінцевий кут,
clockwise - true = проти часової стрілки або false = за часовою)
Подивитися текст коду const canvas = document.getElementById("canvas"); const context = canvas.getContext("2d"); context.beginPath(); context.moveTo(20, 90); context.arc(20, 90, 50, 0, Math.PI/2, false); context.closePath(); context.stroke();
arcTo(x1, y1,x2, y2, r) - малює дугу (x1, y1 - координати початкової точки, x2, y2 - координати кінцевої точки, r - радіус)
Подивитися текст коду const canvas = document.getElementById("canvas"); const context = canvas.getContext("2d"); context.beginPath(); context.moveTo(10, 150); context.arcTo(10, 10, 150, 10, 140); context.closePath(); context.stroke();
quadraticCurveTo(x1, y1, x2, y2) - малює квадратичну криву (x1, y1 - координати початкової точки, x2, y2 - координати кінцевої точки)
Подивитися текст коду const canvas = document.getElementById("canvas"); const context = canvas.getContext("2d"); context.beginPath(); context.moveTo(10, 150); context.quadraticCurveTo(10, 10, 150, 10); context.closePath(); context.stroke();
bezierCurveTo(x1, y1, x2, y2, x3, y3) - малює криву Безьє із заданням координат трьох опорних точок (x та y)
Подивитися текст коду const canvas = document.getElementById("canvas"); const context = canvas.getContext("2d"); context.beginPath(); context.moveTo(30, 100); context.bezierCurveTo(110, 0, 190, 200, 270, 100); context.closePath(); context.stroke();
Текст
fillText(text, x, y) - виведення тексту із заливкою (text - заданий текст, x, y - координати лівої верхньої точки об'єкту)
Подивитися текст коду const canvas = document.getElementById("canvas"); const context = canvas.getContext("2d"); context.font = "30px Verdana"; context.fillStyle = "navy"; context.fillText("Hello world!", 20, 50);
strokeText(text, x, y) - виведення тексту із контуром (text - заданий текст, x, y - координати лівої верхньої точки об'єкту)
Подивитися текст коду const canvas = document.getElementById("canvas"); const context = canvas.getContext("2d"); context.font = "30px Verdana"; context.strokeStyle = "navy"; context.strokeText("Hello world!", 20, 50);
textAlign - вирівнювання по горизонталі (left, right, center, start, end)
Подивитися текст коду const canvas = document.getElementById("canvas"); const context = canvas.getContext("2d"); context.font = "22px Verdana"; context.textAlign = "right"; context.fillText("Right Text", 120, 30); context.textAlign = "left"; context.fillText("Left Text", 120, 60); context.textAlign = "center"; context.fillText("Center Text", 120, 90); context.textAlign = "start"; context.fillText("Start Text", 120, 120); context.textAlign = "end"; context.fillText("End Text", 120, 150);
textBaseline - вирівнювання по вертикалі (top, bottom, middle, alphabetic, hanging)
Подивитися текст коду const canvas = document.getElementById("canvas"); const context = canvas.getContext("2d"); context.font = "22px Verdana"; context.textBaseline="top"; context.fillText("Top",10,100); context.textBaseline="bottom"; context.fillText("Bottom",45,100); context.textBaseline="middle"; context.fillText("Middle",130,100); context.textBaseline="alphabetic"; context.fillText("Alphabetic",205,100); context.textBaseline="hanging"; context.fillText("Hanging",320,100);
measureText() - виведення ширини тексту
Подивитися текст коду const canvas = document.getElementById("canvas"); const context = canvas.getContext("2d"); context.font = "14px Verdana"; const text = context.measureText("Hello world!"); let value = "Ширина тексту = " + text.width; context.fillText(value, 20, 50);
1. Необхідно визначити елемент <canvas> на веб-сторінці:
<canvas id="canvas" width="500px" height="300px"></canvas>
Подивитися текст коду const canvas = document.getElementById("canvas"); const context = canvas.getContext("2d"); context.restore(); context.strokeStyle = "black"; context.fillStyle = "black"; context.lineWidth = 1.0; context.setLineDash([]); context.globalAlpha = 1.0; context.shadowOffsetX = 0; context.shadowOffsetY = 0; context.shadowBlur = 0; context.clearRect(0, 0, 500, 300);
Скидання стану
save() - збереження стану об'єкту Canvas, застосовувати перед зміною властивостей фігури
Подивитися текст коду const canvas = document.getElementById("canvas"); const context = canvas.getContext("2d"); context.clearRect(0, 0, 500, 300); context.save(); context.strokeStyle = "#ff0000"; context.strokeRect (10, 10, 100, 100); context.restore(); context.strokeRect (20, 20, 110, 110);
restore() - відновлення попередньо збереженого стану фігури
