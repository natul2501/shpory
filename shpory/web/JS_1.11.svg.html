D3.js - SVG

D3.js - це быблыотека на мовы Java Script для обробки і візуалізації даних.

SVG - це технологія масштабованої векторної графіки, яку можна виводити безпосередньо в DOM

Розділи: Текст | Лінії і криві | Геометричні фігури | Властивості геометричних фігур і ліній | Групування елементів | Робота з даними елементів веб-сторінки | Прив'язка даних
    Порядок додавання об'єкту до веб-сторінки
    1. Необхідно підключити бібліотеку в <header> на веб-сторінці
    В адресі вказана остання версія v7 і мінімізована версія (суфікс min)     		<script src="https://d3js.org/d3.v7.min.js"></script>
    2. Результат виводиться на веб-сторінку в контейнер: <svg></svg>
    3. Задати властивості контейнера (за замовчуванням width="300px" height="150px") viewBox - специфічний для контейнеру SVG атрибут
    <svg viewBox="0 0 900 300"></svg> - встановлює початок системи координат (х = 0, у = 0 - вісь у направлена зверху вниз), а також співвідношення сторін (ш:в = 900:300)
    1. Текст
    <text>Текст</text> - тег для виводу тексту у контейнер
    властивості можна задавати через стилі css (розмір, шрифт, т.п.)
    Подивитися текст коду <svg> <text x="100" y="30">Текст</text> </svg>
    text-anchor - вирівнювання по горизонталі відносно заданих координат тексту:
    start - лівий край
    middle - центр
    end - правий край
    Подивитися текст коду <svg> <text x="100" y="30" text-anchor="end" >Текст</text> </svg>
    2. Лінії і криві
    <line x1 y1 x2 y2 /> - тег для виводу лінії
    від координати (x1;y1) до координати (x2;y2)
    Подивитися текст коду <line x1="10" y1="15" x2="220" y2="100" stroke="black" />
    <polyline points="x1,y1 x2,y2, x3,y3 ..." /> - складна лінія
    Подивитися текст коду <polyline points="5,135 30,5 55,135 80,5, 105,135" fill="none" stroke="orangered" stroke-width="5" />
    <path d="M mx1 my1 C cx1 cy1, cx2 cy2, cx3 cy3 S sx1 sy1, mx2 my2" /> Геометричний шлях для малювання кривої, атрибут d якого визначає:
    1 - M mx1 my1 - точка, звідки буде малюватися крива
    2 - L lx1 ly1, ... - провести лінію до точки (lx1;ly1)
    2 - C cx1 cy1, ... - провести кубічну криву Безьє до точки (cx1 cy1 cx2 cy2 cx3 cy3)
    2 - Q qx1 qy1, ... - провести кубічну криву Безьє до точки (qx1 qy1 qx2 qy2)
    2 - A ... - провести дугу по координатам (rx ry x-axis-rotation large-arc-flag sweep-flag x y)
    3 - S sx1 sy1 - стоп точка, після якої більше немає вигинів
    4 - mx2 my2 - точка, в якій закінчується крива
    Подивитися текст коду <path d="M20 80 C 90 150, 105 150, 160 80 S 230 10, 300 80" fill="none" stroke="navy" stroke-width="3" />
    3. Геометричні фігури
    <rect x y width height /> - прямокутник із координатами лівого верхнього кута (x;y) шириною width і висотою height
    Подивитися текст коду <rect x="15" y="10" width="120" height="60" />
    <rect x y width height rx ry/> - атрибути для заокруглених кутів rx і ry прямокутника
    Подивитися текст коду <rect x="15" y="10" width="120" height="60" fill="none" stroke="#2980b9" rx="20" ry="20" />
    <circle cx cy r /> - круг із координатами центру (cx;cy) і радіусом r
    Подивитися текст коду <circle cx="100" cy="80" r="50" />
    <ellipse cx cy rx ry /> - еліпс із координатами центру (cx;cy) і радіусами rx і ry
    Подивитися текст коду <ellipse cx="100" cy="80" rx="60" ry="30" fill="#55efc4" stroke="#00b894" />
    <polygon points="x1,y1 x2,y2 ... />" - фігура довільної форми
    Подивитися текст коду <polygon points="70,5 90,41 136,48 103,80 111,126 70,105 29,126 36,80 5,48 48,41" fill="turquoise" stroke="lightseagreen" stroke-width="5" />
    4. Властивості геометричних фігур і ліній
    fill - задати колір заливки; щоб прибрати заливку, використовується значення "none"
    Подивитися текст коду <rect x="15" y="10" width="120" height="60" fill="#2980b9" />
    stroke - задати колір лінії/обводки (назвою, в форматі rgb(0,0,0) або #000000)
    Подивитися текст коду <rect x="15" y="10" width="120" height="60" fill="none" stroke="#2980b9" />
    stroke-width - задати ширину лінії (абсолютне число, яке переводиться в пікселі, або у %)
    Подивитися текст коду <line x1="10" y1="15" x2="220" y2="100" stroke="black" stroke-width="2"/>
    transform = translate(x, [y]) - переміщення фігури по горизонталі (x) і вертикалі (у - якщо не задати, то y=0)
    Подивитися текст коду <rect x="15" y="10" width="120" height="60" /> <rect x="15" y="10" width="120" height="60 transform="translate(15)" fill="none" stroke="red"/>
    transform = scale(sx, [sy]) - масштабує у sx раз по горизонталі і sy раз по вертикалі (якщо sy не вказаний, sy=sx)
    Подивитися текст коду <rect x="15" y="10" width="120" height="60" /> <rect x="15" y="10" width="120" height="60 transform="scale(1.5)" fill="none" stroke="red"/>
    transform = rotate(deg, [cx, cy]) - повертає на кут deg; cx, cy - координати центру повороту (за замовчуванням (0,0))
    Подивитися текст коду <rect x="15" y="10" width="120" height="60" /> <rect x="15" y="10" width="120" height="60 transform="rotate(10)" fill="none" stroke="red"/>
    transform = skewX(deg) - нахиляє елемент вздовж осі х на вказаний кут
    Подивитися текст коду <rect x="15" y="10" width="120" height="60" /> <rect x="15" y="10" width="120" height="60 transform="skewX(10)" fill="none" stroke="red"/>
    transform = skewX(deg) - нахиляє елемент вздовж осі Y на вказаний кут
    Подивитися текст коду <rect x="15" y="10" width="120" height="60" /> <rect x="15" y="10" width="120" height="60 transform="skewY(10)" fill="none" stroke="red"/>
    transform = matrix(a, b, c, d, e, f) - матриця аффінного перетворення:
    x' = a⋅x + c⋅y + e
    y' = b⋅x + d⋅y + f
    Значення літер:
    a - масштаб по осі Х
    b - нахил по осі У
    c - нахил по осі Х
    d - масштаб по осі У
    e - переміщення по осі Х
    f - переміщення по осі У
    Подивитися текст коду <rect x="15" y="10" width="120" height="60" /> <rect x="15" y="10" width="120" height="60 transform="matrix(.3 0 0 .95 55 25)" fill="none" stroke="red"/>
    5. Групування елементів
    <g></g> - теги, всередині яких групують елементи. Використовують для:
    1 - спільної трансформації (атрибут transform);
    2 - спільної стилізації (можна задавати стилі в тегу <g>)
    Подивитися текст коду <svg> <g> <text x="10" y="15">Прямокутник</text> <rect x="10" y="20" width="110" height="80" fill="#16a085" /> </g> </svg>
    6. Робота з даними елементів веб-сторінки
    d3.select("selector") повертає перший елемент із усіх елементів, які відповідають селектору ("selector" - найменування об'єкту; ".selector" - доступ по класу; "#selector" - доступ по ID)
    Подивитися текст коду d3.select("li:last-of-type")повертає останній елемент зі списку d3.select("body").select("ul")можна використовувати кілька рівнів вибірки
    d3.selectAll("selector") повертає всі елементи, які відповідають селектору (у вигляді архіву Array())
    attr() отримує чи встановлює значення атрибуту, наприклад дозволити перетягувати дане зображення:
    Подивитися текст коду function s_attr(){ d3.select("img").attr("draggable", "true"); }
    style() отримує або встановлює стиль елемента, наприклад змінити колір цього тексту
    Подивитися текст коду function s_attr(){ d3.select("dfn").style("color", "blue"); }
    text() отримує або встановлює текстовий вміст
    Подивитися текст коду function s_text(){ const text = d3.select("cite").text(); const svg = document.getElementById("svgC"); svg.innerHTML = "<text x=\"5\" y=\"30\">"+text+"</text>" d3.select("cite").text("ось так"); }
    html() отримує або встановлює html-код елемента
    Подивитися текст коду function s_html(){ const text = d3.select("cite").html(); const svg = document.getElementById("svgC"); svg.innerHTML = "<text x=\"5\" y=\"30\">"+text+"</text>" }
    append("selector") додає новий елемент, тег якого передається в метод як параметр, в кінець вибраного елементу
    Подивитися текст коду function s_append(){ d3.select("body").append("h2").text("Приклад використання оператора append()"); }
    insert("selector1", "selector2") додає новий елемент selector1 перед існуючим елементом selector2
    Подивитися текст коду function s_insert(){ d3.select("table").insert("h2", "table").text("Приклад використання оператора insert()"); }
    remove() видаляє елемент
    Подивитися текст коду function s_remove(){ d3.select("cite").remove(); }
    7. Прив'язка даних
    1. data(variable) отримує через параметр variable дані

    Код прикладу 1 function s_remove(){ const langs = ["JavaScript", "TypeScript", "Python", "Dart"]; d3.select("ul").selectAll("li").data(langs) .join("li").text(item=>item); }
    Код прикладу 2 function s_dataDia(){ // Дані рейтингу мов програмування TIOBE за березень 2025 const data = [ {id:1, lang: "Python", rate: 23.85}, {id:2, lang: "C++", rate: 11.08}, {id:3, lang: "Java", rate: 10.36}, {id:4, lang: "JavaScript", rate: 3.46}, {id:5, lang: "Go", rate: 2.78}, ] const barHeight = 18; d3.select("svg") .selectAll("rect") .data(data) .join("rect") .attr("y", d => d.id * (barHeight + 10) - (barHeight + 10)) .attr("width", d => d.rate * 8) .attr("height", barHeight) .attr("fill", "steelblue"); d3.select("svg") .selectAll("text") .data(data) .join("text") .attr("y", d => d.id * (barHeight + 10) - (barHeight + 10)/2 ) .attr("x", d => d.rate * 8 + 10) .text(d => `${d.lang} (${d.rate}%)`); }
    2. join("selector") додає html-елементи "selector" на веб-сторінку ("selector" - найменування об'єкту; ".selector" - доступ по класу; "#selector" - доступ по ID)
    d3.min(data) повертає мінімальне значення у масиві data
    Подивитися текст коду function s_d_min(){ const data = [3, 8, 21, 13, 1, 2, 5]; const result = d3.min(data); const svg = document.getElementById("svgC"); svg.innerHTML = "<text x="50" y="30">"+data+"</text>"; + "<text x="10" y="50">Мінімальне значення: "+result+"</text>"; }
    d3.max(data) повертає максимальне значення у масиві data
    Подивитися текст коду function s_d_max(){ const data = [3, 8, 21, 13, 1, 2, 5]; const result = d3.max(data); const svg = document.getElementById("svgC"); svg.innerHTML = "<text x="50" y="30">"+data+"</text>"; + "<text x="10" y="50">Максимальне значення: "+result+"</text>"; }
    d3.extent(data) повертає мінімальне та максимальне значення у вигляді масиву з двох елементів
    Подивитися текст коду function s_d_extent(){ const data = [3, 8, 21, 13, 1, 2, 5]; const result = d3.extent(data); const svg = document.getElementById("svgC"); svg.innerHTML = "<text x="50" y="30">"+data+"</text>"; + "<text x="10" y="50">Макс. і мін. значення: "+result+"</text>"; }
    d3.sum(data) повертає суму всіх елементів масиву
    Подивитися текст коду function s_d_sum(){ const data = [3, 8, 21, 13, 1, 2, 5]; const result = d3.sum(data); const svg = document.getElementById("svgC"); svg.innerHTML = "<text x="50" y="30">"+data+"</text>"; + "<text x="10" y="50">Сума всіх елементів: "+result+"</text>"; }
    d3.median(data) повертає медіану масиву
    Подивитися текст коду function s_d_median(){ const data = [3, 8, 21, 13, 1, 2, 5]; const result = d3.median(data); const svg = document.getElementById("svgC"); svg.innerHTML = "<text x="50" y="30">"+data+"</text>"; + "<text x="10" y="50">Медіана масиву: "+result+"</text>"; }
    d3.mean(data) повертає середнє значення
    Подивитися текст коду function s_d_mean(){ const data = [3, 8, 21, 13, 1, 2, 5]; const result = d3.mean(data); const svg = document.getElementById("svgC"); svg.innerHTML = "<text x="50" y="30">"+data+"</text>"; + "<text x="10" y="50">Середнє значення: "+result+"</text>"; }
    data.sort(d3.ascending) data.sort(d3.descending) впорядкування масиву за зростанням / за спаданням
    можна також задати власну функцію сортування
    Подивитися текст коду function s_d_asc(){ const data = [3, 8, 21, 13, 1, 2, 5]; const result = data.sort(d3.ascending); const svg = document.getElementById("svgC"); svg.innerHTML = "<text x="50" y="30">"+data+"</text>"; + "<text x="10" y="50">Сортування за зростанням: "+result+"</text>"; }
    d3.quantile(data.sort(d3.ascending), 0.25) повертає квантиль елементів масиву, відсортованого за зростанням
    Подивитися текст коду function s_d_quant(){ const data = [3, 8, 21, 13, 1, 2, 5]; const result = d3.quantile(data.sort(d3.ascending), 0.25); const svg = document.getElementById("svgC"); svg.innerHTML = "<text x="50" y="30">"+data+"</text>"; + "<text x="10" y="50">Квантиль елементів масиву: "+result+"</text>"; }
    d3.bisect(data.sort(d3.ascending), 11) функція, яка повертає позицію у відсортованому масиві, куди можна помістити певний об'єкт, не порушуючи порядку зростання
    Подивитися текст коду function s_d_bis(){ const data = [3, 8, 21, 13, 1, 2, 5]; const result = d3.bisect(data.sort(d3.ascending), 11); const svg = document.getElementById("svgC"); svg.innerHTML = "<text x="50" y="30">"+data+"</text>"; + "<text x="10" y="50">d3.bisect: "+result+"</text>"; }
